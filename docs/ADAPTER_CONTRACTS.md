# Adapter contracts v1

Every new immutable forecast package supplies procedure/version, history and feature-memory policy, product, panel, source IDs, code/config/environment hashes, input admission and artifact IDs, train/tune/calibration cutoffs, per-game feature cutoff, actual issuance and persistence clocks, functional and fallback. Source available time is distinct from retrieval time. Future target values never enter queries or transformations.

Join by stable player identity, game, target, scoring contract and period. Do not fuzzy-match names. Outcomes retain source revision, finality, explicit participation and missingness. Conflicting terminal states or values without authoritative revision chronology are unresolved. Observed-at alone does not establish a correction. A numerical zero needs complete-source support.

`nick-chart-ppr-v1` requires all sixteen independently mapped primitives in `nfl_v2/scoring.py`, unique fumbles lost and exclusive touchdown credits. A mapping must certify zero semantics and no ordinary reception for a two-point catch. No generic fantasy total is admitted. Expected chart points are a weighted sum of component means; no median, quantile or distribution is derived by adding component medians.

Numeric products preserve mean/median/recipe identity. Anytime TD is a binary rushing-or-receiving event. A point cannot supply a probability law. Discrete log scores require PMF mass. Coherent offered-line probabilities retain push mass; settlement requires authenticated book/line/price/time/jurisdiction/contract and frozen selections. Unauthenticated lines block price/selection claims, not numerical replay.

Source tiers: authentic pregame vintages, qualified as-of reconstruction, current-vintage reconstruction. Information tiers: football-only, qualified current context, authenticated market. Separate comparisons across tiers. No source or code with unverified redistribution license is vendored into V2; external evidence remains attributed and pinned.

History cell admission requires all core regimes, fixed row identities, common permitted features, explicit older memory and week-one fallback. Strict current-information excludes older fitted priors, retrieval, encodings and calibration; historically tuned settings remain disclosed. Invalid or leaky recipes are quarantined. Fixed archived provider forecasts have retraining arms N/A.

Inherited `all_offered` scorer population means all issued lab forecast opportunities, not authenticated bookmaker offers. The later Week7label extension retains all8,096unique query keys. Exact source namespace/team/opponent/completed-game/cutoff matches qualify only explicit statistics; normalized omittedzeros remain missing. Its labels are a new current-vintage grading version, not recovered original capture or full-population skill evidence.
