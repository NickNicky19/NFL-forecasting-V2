There is **one empirical mechanism with three history regimes**. Numeric mean
and lower-median outputs are views of the same arm; anytime rushing-or-receiving
TD uses the empirical binary mean. These are not ten thousand independent NFL
observations or five distinct methods per category. Complex legacy procedures
were not captured by this new adapter. Chart PPR remains explicitly blocked on
its full rare-component/zero/attribution label contract.

The H-CURRENT arm uses eligible 2026 values; H-RECENT uses 2025 plus 2026;
H-MULTI uses 2022–2026. Each queries the player's own same-position empirical
history, then an explicitly named same-arm position fallback, then constant zero
if no supported observations exist. Missing canonical identity or query context
causes abstention. It never triggers a fake prior prediction. The arithmetic
consumes no older outcomes in H-CURRENT, while cohort eligibility is inherited
from the existing producer; this is not a pure-current-information claim for the
complete original selection system.
