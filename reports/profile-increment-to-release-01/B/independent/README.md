## What is new, and what stays closed

The retained E1/E2/E3 procedures already consume attempted down/depth mixture, own conversion history/support, opponent conversion residuals, and mixture-by-residual interactions. The new block adds the distinction between reported offensive opportunities, provider dropbacks, official credited attempts, sacks/scrambles/spikes, past QB shares and marginal dropback context mixtures. It does not repeat the failed aggregate or depth-conditioned catchability additions, confidence intercepts, selective gates, or a source-acceptance rerun.

V1 source extraction is preserved. Before any model fit, V2 corrects the conditional attempt rate to `attempts_on_dropbacks / dropbacks`, retaining 325 credited attempts outside the provider dropback definition in official totals. Known-flag denominators stay explicit. This is a prefit semantic correction; no already-scored NFL forecast was corrected by it. The runner's source-key binding was also fixed before fitting. No other implementation defect was found in the checked new path.

Own QB “opportunities” are attributed passing-event rows, not every offensive opportunity while the QB is active. Team offense/defense use a documented reported rush/pass/dropback proxy; designed play calls, pressure, authenticated starters and all active-QB snaps are not supplied. New defensive values are raw or earlier-league-shrunk, not newly proven opponent-adjusted talent. Field usage and split counts are not causal importance.
