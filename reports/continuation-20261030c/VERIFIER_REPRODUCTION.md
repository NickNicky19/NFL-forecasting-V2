# Run the public verifier exports

Restore the admitted source snapshots and private companion through their approved access process. Supply their local roots through `NFL_V2_QA_SOURCE_ROOT` and `NFL_V2_QA_COMPANION_ROOT`; no root value or private storage locator is embedded in the public exports. Scripts that already take `--source` or `--private` continue to require those explicit inputs. The seasonal feature checker now requires `--source` as well.

Use the exact code, protocol and artifact versions named in each numerical review. The [export map](VERIFIER_PORTABLE_CODE_EXPORT.json) distinguishes the original checker bytes from the public path-only exports. It does not claim that their source hashes are identical. The original private code bundle and all underlying forecast/outcome packets require separate approved offhost restoration.

Examples of entry points are `check_season_scores_independent.py`, `check_season_features_independent.py`, `check_season_history_independent.py`, `check_compact_subgroups_independent.py` and `check_strict_hgb_future_independent.py`. They replay retained evidence; none launches an NFL fit. Their fixed historical panels must stay separate from future grading. Do not provide new 2026 Week 8 outcomes to these checks.
