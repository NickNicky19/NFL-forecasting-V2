## Mathematical and execution contract

For each existing mean parent, the predicted conversion mean is `m(x)=sum_j pi_j(x)*sigmoid(eta_j(x))` over25 earlier-estimated down/depth contexts. With the unchanged `A~NB(mu_A,r)`, the new law uses `Theta~Beta(m*kappa,(1-m)*kappa)` and `C|A,Theta~Binomial(A,Theta)`. Thus `P(C=c)=sum_{a>=c} P(A=a)*BetaBinomial(c|a,m*kappa,(1-m)*kappa)` and `E[C]=mu_A*m` stays fixed. Conditional independence of the latent rate and attempts given the supplied features is an assumption, not a measured fact.

Precision uses the predeclared bounded logistic link in seven named context/support features. Its likelihood uses only earlier-origin out-of-time parent means and eligible historical actual attempts/completions. It does not use in-sample residuals, target-game actual context or an invented player-times-defense multiplier. Existing opponent residuals stay in the frozen parent; no second manual adjustment is applied. Numerical integration omits at most1e-10 attempt-tail mass without renormalization or clipping to observed test maxima. Beta heterogeneity is a conditional game-rate model, not a full posterior over learned parameters/context mixtures. No Monte Carlo was needed.

The full receiver/personnel, actual alignment/routes and joint per-attempt distance mechanism was not executed. Existing inputs contain game summaries for distance/destination, not those richer cells. Lagged summary values affect precision only; unchanged BIN means do not consume them.
