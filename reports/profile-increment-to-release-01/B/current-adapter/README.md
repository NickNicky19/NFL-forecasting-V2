# B typed opportunity-profile current-query adapter

`nfl_v2/qb_opportunity_adapter.py` packages the unchanged frozen opportunity experiment. It adds no model fit, source change, current forecast issuance, consumer admission or website release. The strongest candidate remains determined by the matched results, not this adapter.

Restore with trusted SHA-256 bindings for the exact frozen protocol and typed fit artifact. The adapter verifies the protocol-bound named feature order, source/input bytes and executing dependencies, reconstructs the exact fit-origin training membership and earlier-label prior, and refuses a mismatched model/arm or same-width reordered feature list. JSON arrays are restored directly; no pickle or unsafe model deserialization is used. The original E3 own8/team16 semantics and new fixed profile recipe remain unchanged.

`predict` and `predict_batch` require the explicit canonical feature-name sequence. Each current query supplies canonical player/event/team/opponent/role identity and separately retained pregame membership proof under the existing profile contract. Future queries need no target outcome, final participation row or outcome-availability clock. The query cutoff is passed consistently into old and new feature builders; target outcomes and realized target-game context are unread.

The caller must supply the already-registered expiry/cutoff policy, evidence hash and real request time. There is no new arbitrary source-age limit. The adapter reports unqualified query membership, invalid/missing clock contracts, registered source expiry and registered model expiry separately. It exposes actual latest consumed historical source clocks and preserves the disclosed current-vintage seven-day reconstruction tier. An owner must independently authenticate the supplied membership/clock evidence; merely supplying a well-formed dictionary does not create that evidence.

Sparse/unseen QB histories remain eligible under the qualified query universe, with explicit no-own-history state. The restored learned forest, its frozen five-percent earlier-label prior and the fixed missing-feature zero-plus-indicator treatment stay distinct. No incumbent fallback is silently substituted.

Outputs are typed mean, lower median and the original count law. Optional exact-threshold probabilities preserve Over/Under/push mass and separately report point/probability directions. They are labelled threshold diagnostics, not originally issued selections, qualified offers, odds or EV. A current genuinely captured selection still requires the existing owner-controlled offer/rule/persistence contract.

States: `UNAVAILABLE_QUERY`, `UNAVAILABLE_SOURCE`, `UNAVAILABLE_MODEL`, or `READY_ADAPTER_INFERENCE`. Ready inference is not prepared/delivered/admitted/captured/published/served-verified or five-week-qualified primary use. No authenticated current query universe or consumer receipt is supplied by this package.

Software verification uses one retained R2 historical origin, synthetic membership/expiry fixtures, exact saved-case numerical parity, deterministic restoration, batch/single equality, shuffled identities, named-order rejection, unseen/missing behavior and integer/fractional threshold boundaries. Synthetic role evidence authenticates no historical NFL roster; these checks add zero NFL evaluation rows or weeks.

The reused R0/E3 control artifact lacks an original training-membership hash. Its adapter evidence is explicitly reconstructed from the bound source/recipe and checked against original rowcount/latest-label clocks; it is not described as matching a nonexistent original hash. New R1–R3 models require their retained exact membership hash. Eight adapter software tests include R0 and R2 saved-value parity.
